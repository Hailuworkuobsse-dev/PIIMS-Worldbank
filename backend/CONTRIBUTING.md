# Contributing to PIIMS Backend

## Branch Strategy

| Branch | Purpose |
|---|---|
| `main` | Production (protected, always deployable) |
| `develop` | Integration (features merge here first) |
| `feature/*` | Feature development off `develop` |
| `hotfix/*` | Urgent fixes off `main` |
